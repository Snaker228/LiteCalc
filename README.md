# LiteCalc

Калькулятор на C# — это многофункциональное приложение, предназначенное для выполнения различных математических операций. Оно разработано с использованием современного языка программирования C# и обладает удобным пользовательским интерфейсом.
Основные функции калькулятора включают сложение, вычитание, умножение, деление, а также операции с отрицательными числами и возведение в степень. Кроме того, калькулятор поддерживает работу с дробями, процентами и корнями.
Приложение имеет простой и понятный интерфейс, который позволяет быстро и легко выполнять математические операции. Калькулятор автоматически определяет приоритет операций и показывает результаты вычислений на экране.
Для удобства пользователей калькулятор может быть запущен в нескольких режимах: обычном режиме, научном режиме и режиме памяти. В режиме памяти можно сохранять промежуточные результаты вычислений для последующего использования.
Калькулятор на C# также предоставляет возможность создавать собственные функции и константы, что позволяет пользователям настраивать приложение под свои потребности.
В целом, калькулятор на C# является мощным и универсальным инструментом для выполнения математических операций, который будет полезен как для профессионалов, так и для обычных пользователей.

int x = int.Parse(Console.ReadLine());
string c = Console.ReadLine();
int y = int.Parse(Console.ReadLine());
Console.Write("Итог: ");
switch (c)
{
    case "/":
        Console.WriteLine(x/y); break;
    case "+":
        Console.WriteLine(x + y); break;
    case "-":
        Console.WriteLine(x - y); break;
    case "*":
        Console.WriteLine(x * y); break;
       
}
Console.ReadLine();
